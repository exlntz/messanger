# VOICE

Независимый iOS-мессенджер. Не связан с Telegram.

## Статус

Первая версия в разработке. Подтверждённый объём: SwiftUI, Liquid Glass на iOS 26+, email/пароль, личные чаты, фото, голосовые сообщения и аудиозвонки через Supabase и LiveKit. Сборка неподписанного IPA для последующей подписи AltStore/Sideloadly.

Публичные адреса серверов ещё не предоставлены. Приложение будет запрашивать их при первом запуске. Секретные ключи нельзя помещать в приложение или репозиторий.

Группы, каналы, видеозвонки, боты, push-уведомления и сквозное шифрование в этот этап не входят. Бесплатная подпись Apple ID не поддерживает полноценные push-уведомления и фоновый приём входящих звонков.
