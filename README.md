# VOICE

Нативный iOS-мессенджер VOICE.

VOICE не связан с Telegram, не использует сеть Telegram и не является полным клоном Telegram.

## Что реально есть сейчас

- самостоятельное приложение на SwiftUI для iOS 17+
- нативный Liquid Glass на iOS 26+, на iOS 17-25 используется обычный SwiftUI fallback
- WebKit и WKWebView не используются
- регистрация и вход по email/паролю через Supabase Auth
- только личные чаты один на один
- текст, фото и голосовые сообщения
- аудиозвонки через LiveKit
- токены сеанса хранятся в Keychain
- в приложение вводятся только публичные ключи Supabase `publishable` или `anon`

## Чего сейчас нет

- нет групп
- нет каналов
- нет видеозвонков
- нет ботов
- нет E2EE
- нет push-уведомлений
- нет PushKit
- нет готовой подписанной сборки для прямой установки

## Backend и запуск

Код backend есть в репозитории, но он не развернут. В репозитории нет готовых endpoint-ов и нет рабочих credentials.

Для реального запуска сначала поднимите сервер по [`docs/BACKEND.md`](docs/BACKEND.md), потом введите в приложении:

- Supabase URL
- публичный Supabase publishable или anon key
- LiveKit WSS URL

## Текущее состояние CI

- workflow [`iOS unsigned IPA`](.github/workflows/ios.yml) есть, но последние запуски на `main` сейчас не подтверждают готовый IPA
- workflow [`Backend Security`](.github/workflows/backend.yml) проверяет SQL и security-тесты backend
- актуальные статусы смотрите в GitHub Actions: <https://github.com/exlntz/messanger/actions>

Если workflow iOS завершится успешно, в артефактах run появится `VOICE-unsigned-ipa` с файлом `VOICE-unsigned.ipa`.

Это неподписанный IPA. Он не является готовым подписанным бинарником для прямой установки. Для установки нужна ваша личная валидная подпись через AltStore, Sideloadly или платный Apple distribution path.

## Важные ограничения

- входящие звонки работают только пока приложение открыто и активно на экране. Фонового приёма через PushKit нет
- background audio mode `audio` указан, но работа активного звонка в фоне на реальном устройстве не подтверждена
- экран чата загружает только последние 500 сообщений на диалог
- история звонков загружает последние 100 записей
- поиск людей требует минимум 2 символа и возвращает до 30 результатов
- текстовое сообщение ограничено 4000 символами
- голосовое сообщение ограничено 5 минутами
- медиа для чата ограничены 15 МБ, аватар 5 МБ
- приложение не offline-first и не имеет durable outbox. Неотправленные сообщения не гарантированно дойдут позже автоматически

Не считайте проект полностью проверенным в рантайме, пока не пройдён ручной тест на двух реальных пользователях и двух реальных устройствах.
